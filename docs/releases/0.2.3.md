# JARVISS 0.2.3

[Download for Windows](https://github.com/jamespeirano/JARVISS/releases/download/v0.2.3/JARVISS-Windows-x64.exe) · [Download for Mac](https://github.com/jamespeirano/JARVISS/releases/download/v0.2.3/JARVISS-Mac-Apple-Silicon.dmg)

Windows: 278 MB, Intel/AMD x64, signed by James Peirano. Mac: 338 MB, Apple silicon, signed by Abito Inc. and notarized by Apple.

## What's new

- 38 offline references, including illustrated shelter, navigation and knot guides.
- Read the full offline documents. Chat sources open the cited section; illustrated chapters open at the matching PDF page.
- Search the library, jump between sections, and save text or PDFs.
- Expand the map to full screen. See when voice mode is generating an answer.
- Retry a failed startup connection inside the app without discarding downloads.

## Install

1. Download and install the app. On Mac, drag JARVISS to Applications.
2. Open it and choose **Download everything**.
3. Wait for **Ready offline** before disconnecting internet.

Python, Node and separate model software are not required. Setup downloads a model, voice, the US map and walking data. The wizard shows the download size for your selected model.

## Known issues and testing limits

- Small models can give incorrect answers, even when a relevant document is available. Open cited passages and check the instructions. See [model evaluations](../library-evaluation.md).
- Maps show recorded features. They cannot confirm current access, water quality, supplies or route conditions.
- Hardware microphone compatibility and full first-time setup are still being checked on additional machines. Report your OS, model and exact error in a [bug report](https://github.com/jamespeirano/JARVISS/issues/new/choose).

Mac and Windows automated checks pass, including packaged first launch, the document reader and PDF pages. Signature and checksum checks pass for both installers. These checks do not establish compatibility with every computer.
