# JARVISS 0.2.5

[Download for Windows](https://github.com/jamespeirano/JARVISS/releases/download/v0.2.5/JARVISS-Windows-x64.exe) · [Download for Mac](https://github.com/jamespeirano/JARVISS/releases/download/v0.2.5/JARVISS-Mac-Apple-Silicon.dmg)

## Changes

- Resize or hide either sidebar. Your layout is remembered; double-click a divider to reset its width.
- Keep the original blue JARVIS circle, with clearer Mac window controls and layouts that fit smaller windows and increased zoom.
- Chat replies display headings, lists and tables. Copy or retry an answer, and edit your situation beside Chat.
- Maps have a simpler position menu, copyable directions, route clearing and consistent distance units.
- Open documents by clicking their row. Import, rename or remove your own manuals in Docs.
- Settings include model start/stop, logs, the data folder, shortcuts and local-service recovery.
- Setup offers chat-only downloads and remembers when you choose to set up later.

Includes the data, download, chat, map, voice and group-message fixes from PR #13 and the UI changes from PR #14. Runtime dependencies are unchanged from 0.2.4.

## Supported computers

Windows 10/11 on Intel or AMD x64; macOS 13 or newer on Apple silicon. Windows is signed by James Peirano. Mac is signed by Abito Inc. and notarized by Apple. Setup downloads models, voice and maps separately.

## Validation and known issues

The source changes passed Mac and Windows CI, including backend, startup, setup, chat/voice, document/PDF and responsive UI checks. Local Mac testing also covered all 229 backend tests with installed US maps and real offline searches and walking routes.

Packaged installer checks cover first launch with empty app data, the bundled backend, setup recommendations, document text and illustrated PDF pages. Release verification records report the completed checks and signed-file checksums. This does not replace a full clean-machine data download or physical microphone test.

- Small models can miss details or give unsupported facts. Check cited guides for important decisions.
- Pausing an unfinished basemap restarts that basemap transfer; completed components remain available.
- The Windows installer uses its standard progress bar. Cancel and Close are disabled while files are being written.
- Microphone behavior depends on the physical device and its audio driver.

GitHub, its public release API, the README and [jarviss.live](https://jarviss.live) use the same release assets. Checksums, signature verification, notices and exact application-source information accompany the release. Referenced dependency source archives from previous releases remain required and must not be deleted.
