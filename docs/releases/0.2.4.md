# JARVISS 0.2.4

[Download for Windows](https://github.com/jamespeirano/JARVISS/releases/download/v0.2.4/JARVISS-Windows-x64.exe) · [Download for Mac](https://github.com/jamespeirano/JARVISS/releases/download/v0.2.4/JARVISS-Mac-Apple-Silicon.dmg)

## Changes

- Chat becomes available after the model and voice are ready, while maps finish downloading.
- View setup and pause downloads from any page. Resume keeps completed files.
- Downloads show readable names, size, speed, progress and time remaining.
- Docs search includes imported manuals and hides unrelated results.
- Maps explain when data is still downloading. Walking directions keep the selected place name.
- Two download buttons at [jarviss.live](https://jarviss.live) use the same installers as GitHub.

No changes to models, prompts or runtime dependencies.

## Supported computers

Windows 10/11 on Intel or AMD x64; macOS 13 or newer on Apple silicon. Windows is signed by James Peirano. Mac is signed by Abito Inc. and notarized by Apple. Setup downloads models, voice and maps separately.

## Validation and known issues

The underlying changes passed 130 backend tests, 10 Electron suites, 102 offline walking routes across all 50 states and DC, and Windows/Mac CI. See [validation details](../windows-ux-validation.md).

- Small models can miss relevant details or give unsupported facts. A completed download does not establish answer accuracy.
- Pausing an unfinished basemap restarts that basemap transfer; completed components remain available.
- The Windows installer uses its standard progress bar. Cancel and Close are disabled while files are being written.
- Microphone behavior still depends on the physical Windows device and its audio driver.

The release includes checksums, signature verification, notices and exact application-source information. Unchanged dependency source archives remain linked from v0.2.2; do not delete those archives.
